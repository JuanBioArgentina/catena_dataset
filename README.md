# catena_dataset

This repository includes the datasets needed to perform all the analyses present in the submitted paper to CATENA journal in 2026. The folder under the title data includes two different datasets. Dataset 1: "manuscript_dataset" includes all the models surveyed and used to estimate C efflux. Each column name is the model unique label and the year the model was projected in using the climate data. Dataset 2: "climatic_dataset" includes all the yearly and monthly surveyed climatic variables. 

Datasets will be found within the .zip data folder.
